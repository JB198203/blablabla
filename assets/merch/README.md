## Mettre en ligne sur Fourthwall

1. Créer le compte (à ton nom, avec tes coordonnées de paiement) et choisir « Print on demand ».
2. Ajouter un produit → choisir le modèle (t-shirt noir, etc.) → importer le PNG → le placer.
   Fourthwall indique si la résolution est suffisante pour la taille choisie : rester dans le vert.
3. Prix : le coût de fabrication est affiché, on ajoute sa marge (5 à 10 € sur un t-shirt).
4. Relier la chaîne YouTube (YouTube Shopping) pour que les produits s'affichent sous les clips.
5. Envoyer l'adresse de la boutique : on ajoute un lien « Merch » sur le site.

## À savoir

- Le logo source fait 1289 px de large. Pour un grand dos (30 cm et plus), il faut un logo en plus
  haute définition (export vectoriel ou image 4000 px).
- Le chromé et le logo métal impriment bien en DTG (impression numérique) sur tissu foncé.
  Pour la broderie, utiliser les versions une couleur.
